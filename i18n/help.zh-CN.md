## 01 快速输入与触发转换

- **任意行输入：**在任一数据类型框中输入数值。
- **一键触发：**按 `Enter` 键或点击右侧 `↵` 图标。
- **全量同步：**自动计算并更新其余 9 种数据类型。

> // 支持直接输入以下 3 种格式（不区分大小写）
| 格式类型 | 示例 |
| :--- | :--- |
| 十进制 / 科学计数 | `200` `-32768` `3.14e-2` |
| 十六进制 (0x前缀) | `0x12345678` `0xFF` |
| 二进制 (0b前缀) | `0b11001000` `0b0101` |

## 02 字节序（Endianness）图解

- **字节编号：**标准大端序（高字节在前）依次记为 **A, B, C, D...**
- **独立切换：**每行可单独选择字节序，实时重排当前行显示结果。
- **适用场景：**方便 Modbus 寄存器或 STM32 大小端跨设备调试。

> // 以 32 位数值 0x12345678 为例：
| 字节序模式 | 字节排列 |
| :--- | :--- |
| ABCD (大端) | `A:12` `B:34` `C:56` `D:78` |
| DCBA (小端) | `D:78` `C:56` `B:34` `A:12` |
| BADC (字节交换) | `B:34` `A:12` `D:78` `C:56` |
| CDAB (字交换) | `C:56` `D:78` `A:12` `B:34` |

## 03 视觉分块与无空格复制

- **按字节留白：**16 进制与 2 进制下，每字节自动间隔显示以便阅读。
- **一键无空格复制：**点击输入框右侧 `[COPY_ICON]` 复制图标（或划选复制）会自动剔除间隔并显示 `[OK_MARK]`，可直接粘贴至代码中。

> COPY_DEMO: 界面显示: 0x12 34 56 78 | ──复制──► | 0x12345678

## 04 STM32 转换与量程规范

- **浮点转整型：**遵循 C 标准向零截断
  SUB: 例：`12.9 → 12`，`-12.9 → -12`
- **目标超范围：**源数值超出目标类型量程时提示 `[WARN:超范围]`
  SUB: 例：输入 `uint8 = 200` 时，`int8` 显示超范围
- **源输入越界：**输入值超出当前行量程时，右侧状态栏标红报错
  SUB: 报错或超范围状态下切换进制，不会触发错误转换
